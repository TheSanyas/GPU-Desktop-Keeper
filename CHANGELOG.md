# Changelog

## 1.0 — 2026-10-09

Первый публичный выпуск. Основан на проверенной локальной версии 2.3.8; механизм обхода сохранён.

- Удержание аппаратного Direct3D 11 устройства feature level 11.1 и immediate context.
- Основной режим без вспомогательных буферов; отдельные экспериментальные режимы.
- Восстановление после сна или потери устройства, необязательная проверка доступности GPU.
- Трей, сохранение настроек, светлая и тёмная темы.
- Скруглённые элементы, переключатель солнце/луна, буферизованная отрисовка вкладок.
- Автозапуск через планировщик задач с обычными правами выполнения.
- Исходники, сценарий сборки, проверки без GPU и MIT.
