# GPU Desktop Keeper 1.0

Первый публичный выпуск утилиты для обхода рывков фоновых приложений на дополнительных мониторах при высокой игровой нагрузке на GPU.

Обход основан на удержании собственного аппаратного Direct3D 11 устройства feature level 11.1. Основной режим не создаёт вспомогательных буферов и не отправляет постоянную GPU-нагрузку. Эффект проверен на одной конфигурации Windows 11/NVIDIA; точный механизм внутри драйвера не установлен, результат на других системах не гарантируется.

## Возможности

- Основной режим и отдельные эксперименты с буферами.
- Трей, сохранение настроек и восстановление после сна/потери устройства.
- Светлая и тёмная темы, скругления, отрисовка вкладок с двойной буферизацией.
- Автозапуск через планировщик с обычными правами выполнения.
- Исходники и лицензия MIT.

## Установка

Скачай `GpuDesktopKeeper-1.0-portable.zip`, распакуй в постоянную папку с правом записи и запусти `GpuDesktopKeeper.exe`. Файл `.exe.config` оставь рядом. Для прекращения работы выбери «Выход» в меню трея.

Требуются .NET Framework 4.8 и аппаратное устройство NVIDIA на адаптере по умолчанию с поддержкой feature level 11.1. Обычный запуск не требует повышения прав; создание задачи автозапуска может запросить UAC.

При переходе с локальных тестовых версий закрой прежний Keeper, перенеси свой `keeper-settings.json` и обнови задачу автозапуска, если изменился путь к EXE.

## Проверка выпуска

Сборка без предупреждений, `--check-core` и `--preview` прошли. Native GPU-механизм сохранён из предыдущей проверенной локальной версии. Рабочие настройки Windows/NVIDIA и автозапуск при подготовке релиза не менялись. Отдельные проверки не являются бенчмарком плавности.
